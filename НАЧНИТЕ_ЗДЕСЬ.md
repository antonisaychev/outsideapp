# Пакет передачи проекта Outside → Claude Code

## Как использовать (3 шага)
1. Распакуйте этот архив в удобную папку, например `Документы/outside-project`
2. Установите Claude Code (claude.com/download, вход тем же аккаунтом)
   и откройте в нём папку `outside-project`
3. Первое сообщение Клоду в Code:
   «Прочитай CLAUDE.md и папку docs. Подними backend локально, проверь что
   /health и /auth работают, затем продолжай дорожную карту с модуля users»

## Что внутри
- CLAUDE.md — контекст проекта (Claude Code прочитает его автоматически)
- backend/ — рабочий код API (авторизация готова и протестирована)
- docs/ — все ТЗ, спецификация интерактивности, юридические шаблоны

## Что остаётся в приложении Claude (claude.ai)
- Правки дизайна в Figma (там подключён коннектор)
- Обсуждение продукта, новые ТЗ — там сохранена вся память проекта

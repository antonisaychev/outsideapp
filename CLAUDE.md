# Outside — контекст проекта для Claude Code

## Что это
Outside — соцсеть для экспатов (рабочее название). Основатель — не программист,
объясняй решения простым языком и давай пошаговые инструкции для любых действий,
которые он должен выполнить сам (терминал, сервисы, магазины приложений).
Общение — на русском.

## Ключевые решения продукта (сводка изменений поверх мастера)
- Подписок (follows) НЕТ — удалены из продукта. Мэтч = автодружба
- Регистрация: email+пароль+@никнейм → подтверждение почты 6-значным кодом
- Никнейм: ^[a-z_]{3,30}$, уникальный, ссылка на профиль /@nickname
- Онбординг из 3 ОБЯЗАТЕЛЬНЫХ шагов: имя+пол(+фото), страна (флажок, home_country),
  место (city_id). Пропустить нельзя
- Сброс пароля — тоже кодом из письма (forgot → verify-reset → reset)
- Лайк сервиса = «палец вверх» (подтверждение); сердечко = избранное (favorites)
- 30 зачётных лайков от жителей того же места → сервис в «Рекомендовано»
  (порог в env CONFIRM_THRESHOLD); админ может одобрить досрочно
- Правки карточек сервисов — только админ. Категории создаёт/удаляет админ
- Чат: только текст, только между друзьями, WebSocket, удаления сообщений нет
- В интерфейсах: «Место» (не «Город»), «Категория» (не «Фильтр»)
- Языки интерфейса: ru + en, все строки в словарях
- Блокировка юзера админом — с обязательной причиной, показывается юзеру;
  его сервисы скрываются

## Состояние backend (что уже сделано и ПРОТЕСТИРОВАНО)
- migrations/001_init.sql — все 16 таблиц + сид (Бали/Дубай/Пхукет, 11 категорий)
- /auth полностью: register→verify(код)→login, resend, refresh,
  forgot→verify-reset→reset (кодом), rate-limit регистраций и входов
- Публичные: GET /cities, /categories, /users/check-username, /config, /health
- Почта: nodemailer; без SMTP-переменных коды печатаются в консоль (dev-режим)

## Запуск локально
```
cd backend && npm install
cp .env.example .env   # заполнить DATABASE_URL и JWT_SECRET
npm run migrate && npm start
```

## Дорожная карта backend (делать по порядку, модуль за модулем)
1. users: GET/PATCH /me, аватар (multer → /uploads), онбординг-поля,
   GET /users/:id (или /@nick), поиск ?city_id=&q=, смена пароля, удаление аккаунта
2. friends: заявки/принятие/отклонение/удаление, блокировки, рекомендации
3. services: CRUD + лайки с механикой порога + избранное + жалобы + проверка дублей
4. dating: анкета, колода, свайпы, мэтч→автодружба
5. chats: REST история + WebSocket (message.new, message.read), unread
6. notifications
7. admin: пользователи (блок с причиной), сервисы (одобрить/скрыть/редактировать),
   категории CRUD, жалобы
8. Развёртывание на VPS: пошаговая инструкция для основателя (nginx + pm2 + certbot),
   бэкапы БД, деплой

## Конвенции кода
- Ошибки: JSON { error: 'CODE' } или { errors: {field:'CODE'} }, коды капсом
- Все удаления мягкие (deleted_at / status='hidden')
- Комментарии в коде — по-русски, коротко
- Пагинация: ?page=&limit= (по умолчанию 20, максимум 50)
- Никогда не раскрывать существование email в ответах auth-эндпоинтов

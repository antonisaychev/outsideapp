## Сервер

### Подключиться
```
ssh root@50.6.36.91
```
Пароль — в `SECRETS.local.md`. Если SSH не отвечает, есть запасной путь:
веб-консоль в панели управления хостингом.

### Обновить приложение после изменений в коде
```
cd ~/outside && git pull
cd backend && npm install && npm run migrate
pm2 restart outside-api
```
`npm install` и `npm run migrate` можно пропустить, если не менялись
зависимости и структура базы — но выполнить их лишний раз безопасно.

### Проверить, что всё живо
```
pm2 status                    # запущен ли сервер
pm2 logs outside-api          # логи (последние строки)
curl https://api.outside.ink/health   # вернёт {"ok":true,...,"version":"1.1.0"}
systemctl status nginx
systemctl status postgresql
```

### Приложение выдаёт странную ошибку — сначала проверьте версию сервера
```
curl https://api.outside.ink/health
```
Если `version` меньше, чем в файле `backend/package.json` на Mac, — сервер
работает на старом коде, нужно обновить (команды выше). Половина «багов»
приложения — это просто необновлённый сервер.

### Если что-то сломалось
```
pm2 restart outside-api       # перезапустить приложение
systemctl reload nginx        # перечитать конфиг nginx
nginx -t                      # проверить конфиг перед перезагрузкой
```

## База данных

### Подключиться к базе
```
psql -U outside -h localhost -d outside
```
(пароль в `SECRETS.local.md`; выйти — `\q`)

Полезное внутри psql:
```
\dt                 -- список таблиц
SELECT count(*) FROM users;
\q                  -- выйти
```

### Бэкапы

**Что и где бэкапится:**

| Что | Где хранится | Как часто |
|---|---|---|
| Код | GitHub + архив на Mac | при каждом `git push` |
| База данных | `~/backups` на сервере | автоматически, 3:00 каждую ночь, хранится 14 дней |
| Фото (аватары, сервисы) | `~/backups` на сервере | тем же ночным скриптом |

Посмотреть, что есть на сервере: `ls -lh ~/backups`

Сделать бэкап прямо сейчас вручную (на сервере):
```
PGPASSWORD='ПАРОЛЬ_БД' ~/backup-db.sh
```

⚠️ **Важно:** бэкапы лежат на том же сервере. Если сервер целиком выйдет из
строя — пропадут вместе с ним. Раз в месяц скачивайте копию к себе.

**Скачать всё на Mac** (выполнять в терминале Mac, НЕ на сервере):
```
mkdir -p ~/Downloads/outside-backups
scp root@50.6.36.91:'~/backups/*' ~/Downloads/outside-backups/
```

**Восстановление** (на сервере):
```
# база
gunzip -c ~/backups/outside_ДАТА.sql.gz | psql -U outside -h localhost outside
# фото
tar -xzf ~/backups/uploads_ДАТА.tar.gz -C ~/outside/backend/
```

### Настроить nginx (после переустановки сервера или сброса конфига)
```
bash ~/outside/backend/scripts/tune_nginx.sh
```
Включает HTTP/2, сжатие, кэш соединений и раздачу фотографий. Запускать можно
сколько угодно раз: скрипт правит только недостающее, делает резервную копию
и сам откатывается, если проверка конфига не прошла.

### Проверить, что API целиком работает

После каждого обновления сервера:
```
cd ~/outside/backend && node scripts/smoke_test.mjs
```
Скрипт сам ждёт, пока сервер поднимется после `pm2 restart`, так что запускать
его можно сразу следом одной строкой.
75 проверок: регистрация, вход, профиль, сервисы, друзья, чат, знакомства,
уведомления, админка. В конце — «Пройдено: 75  Провалено: 0». Тестовые
аккаунты (`@smoke.local`) скрипт создаёт и удаляет сам.

### Тестовые аккаунты для проверок

Создать 10 «жителей» (пароль у всех `TestPass123!`):
```
cd ~/outside/backend
psql "$DATABASE_URL" -v owner_email=ваша@почта -f scripts/seed_test_users.sql
psql "$DATABASE_URL" -v owner_email=ваша@почта -f scripts/enrich_test_users.sql
```
Второй скрипт даёт им фото (3-5 штук), описания разной длины и разные страны;
четверо остаются в вашей стране, чтобы колода знакомств не пустовала.

Почту писать **без кавычек** — psql подставит их сам. Если поставить кавычки,
скрипт отработает вхолостую и ничего не изменит.

Удалить всех разом:
```
psql "$DATABASE_URL" -f scripts/remove_test_users.sql
```

### Назначить себя админом в приложении
```
psql -U outside -h localhost -d outside -c "UPDATE users SET role='admin' WHERE email='ваша@почта';"
```

## Разработка на Mac

Все команды выполнять из `~/Downloads/outside-project/mobile`.

### Запустить приложение в симуляторе
```
flutter run
```
Если симулятор не запущен — сначала открыть: `open -a Simulator`

Запустить на конкретном симуляторе (когда их два):
```
flutter devices                          # посмотреть список
flutter run -d "iPhone 17 Pro"
```

### Полезное во время работы `flutter run`
- `r` — быстро применить изменения (hot reload)
- `R` — перезапустить приложение
- `q` — выйти

### Проверить код на ошибки
```
flutter analyze
```

### Установить приложение на свой iPhone

Телефон подключить кабелем и разблокировать. Затем:
```
flutter build ios --release
flutter install --release -d 00008130-001231681021401C
```
(длинное число — идентификатор вашего iPhone 15 Pro; список всех устройств
показывает `flutter devices`)

Первый запуск: **Настройки → Основные → VPN и управление устройством →**
ваш Apple ID → **Доверять**.

⚠️ **Срок жизни 7 дней.** Приложение подписано бесплатным аккаунтом
разработчика, поэтому через неделю перестанет открываться — нужно повторить
две команды выше. Ограничение снимается только платным Apple Developer
Program ($99/год), который всё равно понадобится для App Store.

Идентификатор приложения — `ink.outside.app` (он же пойдёт в App Store).

### Локальный сервер (если нужно тестировать без боевого)
```
cd ~/Downloads/outside-project/backend
npm start
```
и запускать приложение так:
```
flutter run --dart-define=API_BASE_URL=http://localhost:3000
```

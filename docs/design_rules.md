# Правила вёрстки макетов Outside 2.0

Обязательны для каждого экрана на странице «Outside 2.0». Проверяются
скриптом-аудитом (см. низ файла) после каждой партии правок.

## Отступы

| Что | Значение |
|---|---|
| Боковые поля экрана | 24 px с каждой стороны → контент 342 px при ширине 390 |
| Между секциями экрана | 16 px |
| Между элементами группы | 8–12 px |
| Внутри карточек | 12–16 px |
| Кнопка во всю ширину | 342 px, высота 52–56 px |
| Шапка вкладки | заголовок на y≈62, контент начинается от низа шапки + 8–12 px |
| Навбар вложенного экрана | «назад» x=16 y=56, заголовок по центру y=66, контент от y=118 |
| Таб-бар | прижат к низу, верхняя граница 1 px |
| Липкая панель | контент выше неё минимум на 8 px |

## Текст

- Любой текст длиннее половины ширины экрана — `textAutoResize: HEIGHT`
  с явной шириной (обычно 342, по центру — 280–320). Авто-ширина запрещена:
  она даёт «прилипание» к краям и вылезание.
- Плейсхолдеры — цвет «Нейтральный/400», значения — «Нейтральный/800».
- В поле плейсхолдер и значение не путать: точки ••• — только для паролей.

## Функционал

- На макете есть только контролы, существующие в приложении, — и все
  контролы приложения присутствуют на макете. Референсы (Airbnb, Tinder,
  Telegram) — источник подачи, не функций.
- У каждого раздела есть состояния: обычное, пустое, ошибка; у кнопок-
  переключателей — оба положения; у сообщений — ✓ и ✓✓.
- Каждый экран, кроме вкладок, имеет контрол возврата. Вкладки — таб-бар.

## Чек-лист самопроверки (после каждой партии)

1. Прогнать аудит-скрипт (границы секций, границы экранов, авто-ширина
   текстов, тексты шире родителя).
2. Скриншот каждого нового/изменённого экрана — смотреть как чужую работу:
   отступы, выравнивания, обрезания, дубли смыслов.
3. Сверить контролы с приложением (открыть соответствующий экран Flutter).
4. Пройтись по текстам: нет ли плейсхолдеров-точек вне паролей, лишних «?»
   в заголовках, несуществующих данных.

## Аудит-скрипт (запускать в use_figma)

Проверяет: вылезание за секции; вылезание за экраны 390×844; текстовые узлы
с авто-шириной больше 342; тексты шире родителя. Возвращает список проблем —
пустой список обязателен перед сдачей работы.

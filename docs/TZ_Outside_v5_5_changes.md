# ТЗ v5.5 — Правки логики (дополнение к мастер-ТЗ v5, v5.3)

## 1. Подтверждение почты кодом (ВОЗВРАЩЕНО)
Регистрация: email+пароль → экран «Подтвердите почту»: 6-значный код из письма.
- Код живёт 10 минут; повторная отправка через 60 сек; 5 попыток ввода
- Пока почта не подтверждена — вход в приложение невозможен (при повторном входе снова экран кода)
- Плюс решения: восстановление пароля всегда работает, боты отсекаются
```
POST /auth/register {email,password} → отправка кода
POST /auth/verify  {email,code}      → токены, статус email_verified=true
POST /auth/resend  {email}
users: + email_verified BOOLEAN DEFAULT false
```

## 2. Восстановление пароля — тоже кодом (ПЕРЕДЕЛАНО)
Было: ссылка из письма. Стало: Забыли пароль (email) → «Код из письма» (6 цифр) → «Новый пароль».
```
POST /auth/forgot        {email}            → отправка кода
POST /auth/verify-reset  {email, code}      → reset_token (15 мин)
POST /auth/reset         {reset_token, new_password}
```

## 3. Блокировка пользователя админом — с причиной
В админке при нажатии «Заблокировать» открывается диалог: поле «Причина блокировки»
(обязательное) + предупреждение «Причина будет показана пользователю». Это закрывает
несостыковку: экран «Аккаунт заблокирован» показывает причину — теперь ей есть откуда взяться.

## 4. Нейминг в админке: «Сервисы», не «Карточки»
Табы админки: Пользователи · Сервисы · Жалобы. Во всех текстах интерфейса — «сервис/сервисы».

## 5. Жалобы — добавлена форма
Шторка «⋯» на чужом профиле: «Пожаловаться» / «Заблокировать» / Отмена.
Форма жалобы: причина чипами (Спам · Мошенничество · Оскорбления · Другое) +
комментарий (необязательно) → в админку. Та же форма — для жалоб на сервис.
```
user_reports: + reason_type ENUM('spam','fraud','abuse','other')
service_reports: + reason_type (тот же ENUM)
```

## 6. Прочие правки интерфейсов (из аудита)
- Настройки: дубль тумблера знакомств убран — один пункт «Знакомства ›» (тумблер живёт в анкете); добавлен пункт «Администрирование» (виден только role=admin)
- Экран Сервисов: плавающая кнопка «+» (вход в форму добавления); колокольчик уведомлений в шапке
- Экран Знакомств: в шапке иконки «Мои мэтчи» и «Анкета»
- Экран Друзей: иконка поиска людей в шапке
- Новый экран «Профиль друга»: кнопки «Написать» + «✓ Друзья»
- Новые экраны: Редактировать профиль · Смена пароля · Заблокированные · Empty-state (шаблон)
- Холст Figma перестроен по 6 юзер-флоу с подписями рядов

## Итоговая карта: 39 фреймов / 6 потоков
1. Регистрация и вход: Приветствие → Регистрация → Код почты → Онбординг ×3 → Вход → Забыли пароль → Код → Новый пароль → Заблокирован
2. Гость и Сервисы: Auth-gate → Сервисы → Карточка сервиса → Добавить сервис
3. Знакомства: Включение → Колода → Мэтч → Анкета → Мои мэтчи
4. Друзья и общение: Поиск → Друзья → Профиль чужой → Профиль друга → Шторка ⋯ → Жалоба → Сообщения → Чат
5. Профиль и настройки: Профиль → Настройки → Ред. профиля → Смена пароля → Заблокированные → Уведомления → Empty-state
6. Админка: Пользователи → Диалог блокировки → Сервисы → Жалобы

# Outside — Спецификация интерактивности и состояний (v1)
## Поведение каждого элемента на 44 экранах. Основа для кода.

---

# 0. ГЛОБАЛЬНЫЕ ПРАВИЛА (действуют на всех экранах)

**Состояния любого экрана со списком/данными:**
1. Загрузка — скелетоны (серые блоки формы контента), не спиннер на пустом фоне
2. Ошибка сети — иллюстрация + «Не удалось загрузить» + кнопка «Повторить»
3. Пусто — empty-state по шаблону (экран 38): иллюстрация + текст + действие
4. Контент

**Кнопки:** Primary активна только когда выполнены условия формы; иначе — вид Button/Disabled и тап игнорируется. Во время запроса — спиннер внутри кнопки, повторный тап заблокирован.
**Поля:** ошибка = стиль Input/Error + текст причины под полем (красный, 13px). Ошибка снимается при изменении поля.
**Тосты** (всплывашки снизу, 2 сек): «Ссылка скопирована», «Сохранено», «Жалоба отправлена», «Добавлено в избранное» и т.п.
**Гость:** любой POST-тап → auth-gate (23); после входа отложенное действие выполняется.
**Оффлайн-тап:** тост «Нет соединения».

# ПОТОК 1 · РЕГИСТРАЦИЯ И ВХОД

## 01 Приветствие
- «Создать аккаунт» → 03. «Войти» → 02. «Продолжить без регистрации» → 04 (гостевой режим)
- Состояний ошибок нет (статичный экран)

## 03 Регистрация
- Поля: Email (формат + «уже зарегистрирован — Войти?» по blur/сабмиту), Пароль (≥8), Повтор (совпадение), @никнейм (^[a-z_]{3,30}$; онлайн-проверка занятости: серый «проверяем…» → зелёное «свободно» / красное «занято»)
- «Создать аккаунт» активна когда все 4 поля валидны → POST /auth/register → 29
- Ошибки сервера показываются под соответствующим полем

## 29 Подтвердите почту
- 6 ячеек: автофокус, автопереход между ячейками, вставка кода из буфера целиком
- Неверный код → ячейки красные + трясутся + текст «Неверный код, осталось N попыток»; 5 неверных → код аннулирован, «Отправить новый»
- Таймер 60 сек → превращается в ссылку «Отправить код повторно»
- Верный код → авто-сабмит без кнопки → онбординг 15. Кнопка «Подтвердить» — дубль для набравших вручную
- «‹» назад → на 03 (аккаунт в статусе неподтверждённого; повторная регистрация тем же email = переотправка кода)

## 15–17 Онбординг (шаги нельзя пропустить)
- 15: «Далее» активна при Имя+Фамилия+Пол; фото опционально («+» → системный выбор из галереи/камеры → превью с «изменить»)
- 16: «Далее» активна при выбранной стране; тап по плитке = выбор (одиночный); «Другая страна…» → поиск по полному списку стран
- 17: «Готово» активна при выбранном месте → PATCH /me → главный экран (04)
- Выход из приложения посреди онбординга → при входе возврат на первый незаполненный шаг

## 02 Вход
- «Войти» активна при заполненных полях → ошибки: «Неверный email или пароль» (общая, под формой, без уточнения какое поле — безопасность); 5 неудач → задержка 60 сек с таймером
- Вход с неподтверждённой почтой → 29
- «Забыли пароль?» → 24. «Нет аккаунта? Создать» → 03

## 24 → 30 → 31 Сброс пароля
- 24: «Отправить код» при валидном email → 30 (если email не найден — всё равно «Код отправлен», без раскрытия существования аккаунта)
- 30: логика ячеек = экрану 29; верный код → 31
- 31: «Сохранить и войти» при валидном пароле+повторе → авторизация → 04

## 25 Аккаунт заблокирован
- Показывается после успешного входа заблокированного; причина из blocked_reason
- «Написать в поддержку» → почтовый клиент на support@[домен] с темой «Блокировка @nickname»
- «Выйти» → 01

# ПОТОК 2 · ГОСТЬ И СЕРВИСЫ

## 23 Auth-gate (шторка)
- «Создать аккаунт» → 03, «Войти» → 02; свайп вниз/тап по фону = закрыть, действие отменено
- После успешного входа: возврат на исходный экран + автовыполнение отложенного действия + тост

## 04 Сервисы
- Шапка: ♡ → 43 Избранное (гость → auth-gate); колокольчик (+красная точка при непрочитанных) → 18; «Бали ˅» → шторка выбора места просмотра (список из /cities; не меняет место в профиле!)
- Табы: Рекомендовано (сортировка по 👍 убыв.) / На проверке (новые сверху, прогресс N/30)
- Чипы категорий: «Все» + активные категории; одиночный выбор; фильтруют текущий таб
- Карточка: тап → 05; ♡ на фото → в избранное/из избранного (заливка сердца); 👍 счётчик — только отображение
- FAB «+» → 06 (гость → auth-gate)
- Пусто (в «На проверке»): «Пока нет сервисов на проверке. Добавьте первым!» + кнопка

## 05 Карточка сервиса
- «‹» назад (нужно ДОБАВИТЬ на макет — см. пробелы); ♡ → избранное
- «Сайт» → браузер (website_url); скрыта если ссылки нет. «На карте» → карты (map_url); скрыта если нет
- «👍 Рекомендую» → лайк; повторный тап = снять; состояние после лайка: залитая кнопка «✓ Вы рекомендуете». Свой сервис лайкать нельзя (кнопка скрыта, вместо неё бейдж «Ваш сервис»)
- «Добавила: Анна» → профиль автора. Меню «⋯» (ДОБАВИТЬ) → шторка «Пожаловаться»
- Для карточки «На проверке»: вместо 👍-кнопки — «Подтвердить (18/30)»; жители другого места видят прогресс без кнопки + подпись «Подтверждают жители Бали»

## 06 Добавить сервис
- «Отправить на проверку» активна при: Название + Описание + Фото + Категория (ссылки опциональны)
- Чип «Категория» → шторка 40 (радио, тап = выбор и закрытие; чип становится выбранным с названием)
- Чип «Место: Бали» → шторка выбора места
- Фото: тап → галерея/камера → кроп 4:3 → превью с «заменить»
- Сабмит: проверка дублей → если похожие найдены: шторка «Возможно, уже добавлен» со списком → «Всё равно добавить» / открыть существующий
- Успех → тост «Отправлено на проверку» → 04, таб «На проверке»

## 40 Выбор категории — радио-список из GET /categories; тап = выбрать и закрыть
## 43 Избранное — сетка сохранённых; ♡ на карточке = убрать (с анимацией исчезновения); пусто: «Сохраняйте сервисы сердечком» + «К сервисам»

# ПОТОК 3 · ЗНАКОМСТВА

## 19 Включение знакомств
- Показывается при первом входе в таб (или если is_active=false)
- «Включить»: если не заполнены пол/дата рождения → сначала анкета 20 с подсказкой; иначе is_active=true → 07
- «Не сейчас» → остаёмся на заглушке (этот же экран без модалки, таб доступен)

## 07 Знакомства (колода)
- Свайп вправо/♥ = лайк; влево/× = пропуск; анимация улёта карточки
- Тап по карточке → полный профиль (13)
- Лайк, вызвавший мэтч → экран 08 поверх
- Иконка-слайдеры → 20 Анкета
- Колода кончилась → empty: «Вы посмотрели всех в Бали. Загляните позже» 
- Лимит 100 лайков/день → тост «Лимит лайков на сегодня»

## 08 Мэтч
- «Написать сообщение» → чат 09 с этим человеком; «Позже» → назад в колоду
- Дружба и диалог уже созданы к моменту показа экрана

## 20 Анкета знакомств
- Тумблер «Участвовать» — мгновенный PATCH (без кнопки Сохранить); off → карточка исчезает из колод
- Чипы «Что ищете» / «Кого показывать» — одиночный выбор
- «Дата рождения» → системный date picker; обязательна для is_active=true
- «Мои мэтчи ›» (ДОБАВИТЬ строку — вход в 21, см. пробелы)
- «Сохранить» — для полей анкеты (кроме тумблера)

## 21 Мои мэтчи — «Написать» → 09; тап по строке → профиль; пусто: «Мэтчей пока нет — свайпайте!»

# ПОТОК 4 · ДРУЗЬЯ И ОБЩЕНИЕ

## 22 Поиск людей
- Поиск live по мере ввода (debounce 300мс) по имени/фамилии/@нику
- Чипы: «🇷🇺 Земляки» (home_country=мой) / «Все на Бали»; флаг чипа = флаг юзера
- «+ Добавить» → заявка; состояние кнопки: «+ Добавить» → «Отправлено ✓» (тап = отменить заявку, с подтверждением)

## 11 Друзья
- Табы: Мои друзья / Входящие · N / Исходящие
- Входящая заявка: «Принять» → в друзья (строка переезжает в Мои друзья) / «Отклонить» → исчезает (без уведомления отправителю)
- Исходящие: строка + «Отменить»
- «⋯» у друга → шторка 45: Написать / Удалить из друзей (с подтверждением 46) / Заблокировать
- Рядом с «⋯» в каждой строке друга — иконка чата 💬: тап → сразу диалог 09 с этим другом (быстрый путь, минуя шторку)
- Лупа → 22. Пусто: экран 38 («Найти людей»)

## 13 Профиль чужой / 35 Профиль друга
- Копирование: тап по ⧉ или @nick → буфер + тост
- 13: «Добавить в друзья» → «Заявка отправлена» (тап = отменить); если ОН отправил мне → кнопки «Принять/Отклонить»
- 35: «Написать» → 09; «✓ Друзья» → шторка (Удалить из друзей)
- «⋯» → шторка 36: «Пожаловаться» → 37; «Заблокировать» → подтверждение → блок (профиль закрывается)
- Счётчик «Рекомендации» → тап = список сервисов этого человека (фильтр раздела Сервисы по автору)

## 37 Форма жалобы
- «Отправить жалобу» активна при выбранной причине; «Другое» без комментария — недостаточно (подсказка)
- Успех → тост «Жалоба отправлена, мы разберёмся» + закрытие

## 10 Сообщения
- Тап по диалогу → 09 (бейдж обнуляется); сортировка по последнему сообщению
- Пусто: «Пока нет диалогов. Сообщения доступны между друзьями» + «К друзьям»

## 09 Чат
- Отправка: активная стрелка при непустом тексте; сообщение появляется мгновенно со статусом ✓ (optimistic), при ошибке — «!» и «Повторить»
- Подгрузка истории при скролле вверх; ✓✓ при прочтении собеседником
- Тап по шапке → профиль (35)
- Если собеседник удалён/заблокирован: поле ввода заменяется плашкой «Вы не можете писать этому пользователю»

# ПОТОК 5 · ПРОФИЛЬ И НАСТРОЙКИ

## 12 Профиль свой
- ⚙ → 14; ⧉ → копия ссылки; счётчики: Друзья → 11, Рекомендации → мои сервисы (включая «На проверке» с прогрессом)
- «Редактировать профиль» → 32

## 14 Настройки
- Каждая строка «›» ведёт на свой экран; Email — не тапабелен (только просмотр)
- «Язык» → шторка Русский/English (применяется мгновенно)
- «Знакомства» → 20; «Администрирование» — строка видна ТОЛЬКО при role=admin → 26
- «Выйти» → подтверждение → 01
- «Удалить аккаунт» → экран-предупреждение (что будет удалено) → ввод пароля → удаление → 01

## 32 Редактировать профиль
- «Сохранить» активна при наличии изменений; Имя/Фамилия не могут стать пустыми
- Место/Страна/Пол/Дата — шторки выбора; фото — галерея/кроп
- Несохранённые изменения + «‹» → «Выйти без сохранения?»

## 33 Смена пароля — активна при 3 валидных полях; неверный текущий → ошибка под полем; успех → тост
## 34 Заблокированные — «Разблокировать» → подтверждение → строка исчезает; пусто: «Список пуст»
## 18 Уведомления
- Открытие = read-all (бейдж колокольчика обнуляется)
- Принять/Отклонить работают прямо из строки (после — строка обновляется на «Вы теперь друзья»)
- Тап по уведомлению → соответствующий экран (профиль/карточка/чат)

# ПОТОК 6 · АДМИНКА (все экраны — только role=admin, иначе 403)

## 26 Пользователи
- Поиск по email/имени/@нику; «Заблокировать» → диалог 39; «Разблокировать» → подтверждение
- Тап по строке → профиль пользователя

## 39 Диалог блокировки — «Заблокировать» активна только при заполненной причине
## 27 Сервисы
- Чипы: статус (Все/На проверке/Рекомендовано) + Место — меняют параметры запроса
- «Одобрить» (только у pending) → подтверждение → статус recommended + уведомление автору
- «Редактировать» → 41; «Скрыть» → подтверждение с причиной (опц.) → hidden + уведомление автору
## 41 Редактирование сервиса — «Сохранить изменения» при валидной форме; действует для любого статуса
## 42 Категории
- «Добавить» → диалог 44; «✕» → если есть активные сервисы: тост «Нельзя удалить: N сервисов»; иначе подтверждение → удаление
## 44 Новая категория — «Создать» активна при обоих названиях; дубль имени → ошибка под полем
## 28 Жалобы
- «Принять меры» → карточка сервиса (41) или профиль пользователя — в зависимости от типа жалобы
- После разбора: «Отклонить жалобу» / решение по объекту → жалоба уходит из списка

# УДАЛЕНИЕ ДРУГА (новые экраны 45–46)

- 45 «Шторка — друг»: имя, действия: Написать / Удалить из друзей (красный) /
  Заблокировать (красный) / Отмена

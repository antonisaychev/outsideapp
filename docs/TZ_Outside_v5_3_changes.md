# ТЗ v5.3 — Изменения продукта (дополнение к мастер-ТЗ v5)

## 1. Подписки УДАЛЕНЫ из MVP
Решение основателя: функционал подписок не нужен.
- Убрано: таблица `follows`, эндпоинты `/follows/*`, кнопка «Подписаться», счётчики «Подписчики/Подписки»
- Мэтч в знакомствах = просто автодружба (без «взаимных подписок»)
- Счётчики в профиле теперь: **Друзья** и **Рекомендации** (число карточек сервисов, добавленных пользователем)
- Лента в будущих версиях будет строиться от друзей

## 2. Онбординг после регистрации (3 ОБЯЗАТЕЛЬНЫХ шага)
После создания аккаунта пользователь попадает в онбординг. Пропустить шаги НЕЛЬЗЯ:
кнопка «Далее»/«Готово» неактивна, пока все поля шага не заполнены/не выбраны.
Следствие для БД: после онбординга first_name, last_name, gender, home_country,
city_id всегда заполнены (NOT NULL логически; аватар остаётся необязательным).
Незавершённый онбординг: при следующем входе пользователь возвращается на
первый незаполненный шаг.

**Шаг 1 из 3 — «Как вас зовут?»**
Фото (кружок с «+»), Имя, Фамилия, Пол (чипы Мужской/Женский; пол обязателен для сохранения шага)

**Шаг 2 из 3 — «Откуда вы?» (выбор флажка)**
Сетка стран с флагами: 🇷🇺 🇺🇦 🇰🇿 🇬🇧 🇩🇪 🇺🇸 🇫🇷 и др. + поиск.
Выбранная страна = `home_country` — **поле возвращается в таблицу users**:
```sql
users: + home_country CHAR(2) NULL   -- ISO 3166-1, напр. "RU"
```
Флаг отображается в профиле в связке «🇷🇺 → Бали» и используется в подборках
(«земляки в вашем городе») и в будущих фильтрах рекомендаций.

**Шаг 3 из 3 — «Где вы живёте?»**
Список городов из справочника: Бали 🇮🇩 · Дубай 🇦🇪 · Пхукет 🇹🇭 → `city_id`. Кнопка «Готово».

Кнопки «Пропустить» на шагах нет. Шаги — экраны 15–17 в Figma.
